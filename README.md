## 🏆 Featured Capstone Projects
*Independent production applications designed, architected, and deployed from scratch.*

### 🏔️ Trekking Management Application (MAD-1 Capstone)
* **Architecture:** Robust MVC pattern separating programmatic SQLAlchemy schemas, modular functional route boundaries, and dynamic UI extensions.
* **Security & Access Control:** Implemented explicit role-based user token session routing matrices (`admin_only`, `staff_only`, `trekker_only`) parsing 3 critical access endpoints (Admin, Trek Staff, and Trekkers).
* **Data Flow Mechanics:** Structured programmatic SQLite pipelines maintaining transaction-safe relational maps across custom `User_Credentials`, `Staff_Profile`, `Trekker_Profile`, `Trek`, and `Booking` entity sets. Includes transactional slot allocation handlers that dynamically adjust available trek capacities upon staff-side booking status approvals.
* **Tech Stack:** `Python` `Flask` `Flask-SQLAlchemy` `SQLite` `Jinja2` `HTML5/CSS3` `uv Package Manager`
